📊 Retail Sales Performance Analysis

An Excel-based data analytics project that transforms raw retail transaction data into meaningful business insights through data cleaning, KPI analysis, PivotTables, and dashboard visualization.

🎯 Objective

Analyze retail sales data to understand:

- Revenue and profitability
- Product and category performance
- Regional performance
- Monthly sales trends
- Customer value
- Discount impact on profit

🧹 Data Preparation

The dataset was cleaned and validated by handling:

- Missing values
- Duplicate records
- Invalid values
- Date inconsistencies
- Data-quality issues

📊 Dashboard

The final dashboard includes:

- Monthly Revenue Trend
- Revenue by Category
- Revenue by Region
- Top 5 Products by Revenue
- Profit Margin by Product
- Top 5 Customers by Revenue

🛠️ Tools Used

Microsoft Excel | PivotTables | PivotCharts | Data Cleaning | Data Analysis | Data Visualization

📌 Project Workflow

Raw Data → Cleaning → Analysis → KPI Calculation → PivotTables → Visualization → Dashboard → Insights
